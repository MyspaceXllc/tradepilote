TradePilot 2.9.5 - Shark Reactivation

This package restores the Shark Sell, Shark Buy and Shark Both buttons so they are not visually disabled by the optional shark settings readiness gate. They are only disabled while another command is busy. The command handler still validates that a connected device is selected and reports errors normally.

Also retains the previous 2.9.4 changes: UTC clock, Close Winners only, Double Trade, and Fusion M1/MTF work.
